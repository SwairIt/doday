# Doday in action

- Canvas: 1920 × 1080, 30 fps, 15 s. Silent, manual playback on landing.
- Ground #fffefa, ink #292929, accent #7053cc, close #eee9f7.
- Local Cyrillic / Latin Inter, 48 px titles, 30 px chapter numbers.
- 0–4.8 s: real task entry/result, camera 1 → 1.12 → 1.
- 4.8–8.9 s: project board navigation; steady camera while the UI changes.
- 8.9–12 s: return to Today and open a real task.
- 12–15 s: wordmark and getdoday.ru; 400 ms settle, then readable hold.
- Banned: invented application controls, purple glows, particles, rotating
  devices, stock testimonials, autoplay, unlicensed music, remote render fonts.

Source: Doday running on an isolated database with fictional study/life tasks.
No production customer data is used.
