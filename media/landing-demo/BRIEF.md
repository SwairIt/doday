The user explicitly requested autonomous research, installation, video creation
and a complete landing redesign while preserving all existing sections.

Selected direction: a short, silent product demonstration using actual Doday UI
captured from an isolated database populated with fictional study/life tasks.
Use the site's light interface, Cyrillic Inter, a warm white ground and flat
violet accents. Show a real added task, project board and task panel; no invented UI.
Embed with native controls and no automatic playback or download. The page
remains usable with JavaScript, animation or video unavailable.

The alternative concepts considered were a kinetic typography manifesto, a
day-in-the-life montage, a reverse countdown of distractions, and a handwritten
letter from the user's future self. Product evidence best serves this landing.
No separate approval stops: the user explicitly said to decide and make it.

Tooling: heygen-com/hyperframes, pinned to the available npm version 0.8.220.
The newly advertised 0.8.221 returned npm ETARGET during setup. Skill refresh
reported the retirement of product-launch-video; the current HyperFrames
contract and its launch/format/motion/review references govern the build.
