Ты открываешь Razbery впервые и видишь список предметов. Задача по «математике» — но у тебя 8 класс, и предмет в дневнике называется «алгебра». Выбрать «математику» или «алгебру»? Класс — указывать? А если задача из олимпиады, а не по программе?

Каталог Razbery устроен просто — предмет, потом класс, — но пара неочевидных моментов есть, и от них зависит, найдут ли твой вопрос отвечающие и найдёшь ли ты чужой разбор. Ниже — как каталог устроен, какой предмет выбирать, зачем нужен класс и как использовать сортировки.

## Структура: предмет → класс → вопросы

Адреса устроены одинаково для всего:

| Адрес | Что показывает |
|---|---|
| `/qa/` | Главная: предметы, свежие вопросы |
| `/qa/s/fizika` | Все вопросы по физике, любой класс |
| `/qa/s/fizika/8` | Физика, 8 класс |
| `/qa/q/<номер>-<заголовок>` | Один вопрос с ответами |
| `/qa/search` | Поиск с фильтрами по предмету и классу |

Классы — с 5 по 11. Начальная школа отдельно не выделена: для неё есть предмет «окружающий мир», а математика 1–4 классов попадает в «математику» без указания класса.

У каждого вопроса ровно один предмет (обязательно) и один класс (необязательно). Это значит, что вопрос по физике с элементами математики живёт в физике — и искать его надо там.

## Пятнадцать предметов и что куда относить

| Предмет | Что сюда | Пограничные случаи |
|---|---|---|
| Математика | 5–6 класс, всё; арифметика, дроби, проценты, текстовые задачи | Проценты в 9 классе — всё равно сюда или в алгебру, оба варианта найдут |
| Алгебра | 7–11: уравнения, функции, степени, логарифмы, тригонометрия, производная | Текстовая задача, решаемая уравнением, — сюда |
| Геометрия | 7–11: планиметрия, стереометрия, векторы | Координатная плоскость — если про фигуры, сюда; если про функции — алгебра |
| Физика | 7–11 | Задача с формулой из физики, где «не получается математика», — всё равно физика |
| Химия | 8–11 | Расчёты по формулам — химия, не математика |
| Биология | 5–11 | Задачи по генетике — сюда |
| Русский язык | Орфография, пунктуация, все виды разбора | Сочинение по литературе — литература; сочинение ЕГЭ по русскому — русский |
| Литература | Анализ произведений, стихотворений, образов | |
| Английский | Грамматика, времена, артикли, слова | Другие иностранные — пока тоже сюда с пометкой в заголовке |
| История | Россия и мир | Даты, причины-следствия, термины |
| Обществознание | Право, экономика, политика, социология | |
| География | Физическая и экономическая, задачи по картам | |
| Информатика | Алгоритмы, Python, системы счисления, логика | Задача по логике из математики — можно и в алгебру |
| ОБЖ | | |
| Окружающий мир | Начальная школа | |

Правило для пограничных случаев: **предмет тот, по которому задача задана в школе**. Отвечающие сидят по своим предметам — физик увидит вопрос в физике, а в математике его может не заметить.

## Математика или алгебра: как выбрать

Самый частый вопрос. Ответ по классам:

- **5–6 класс** — всегда «математика», предмета «алгебра» ещё нет.
- **7–11 класс** — «алгебра» для алгебры, «геометрия» для геометрии. «Математика» в старших классах — для того, что не относится явно ни туда, ни сюда: логические задачи, олимпиадные, теория вероятностей на пересечении.

Если сомневаешься между алгеброй и математикой в 7–9 классе — бери алгебру: там больше отвечающих, и по сортировке «свежие» твой вопрос увидят быстрее.

> **Совет:** посмотри, как называется предмет в твоём расписании. Если «математика» (так бывает в 10–11 классах, где алгебру и геометрию ведут вместе) — всё равно раздели: уравнение в алгебру, треугольник в геометрию. Так разбор найдут те, кому он нужен.

## Зачем указывать класс

Класс необязателен, но полезен по трём причинам:

1. **Отвечающий подстроит объяснение.** Задачу на движение в 6 классе разбирают по действиям, в 8-м — через уравнение. Без класса тебе могут объяснить «не по-вашему», и на контрольной это станет проблемой.
2. **Тебя найдут в фильтре.** Кто-то ищет «встречное движение, 6 класс» — вопрос без класса в такой поиск не попадёт.
3. **Каталог по классу — это твой список типовых задач** перед контрольной. Чем больше вопросов с классом, тем полезнее каталог всем.

Когда класс *не* стоит указывать: тема из другого класса (готовишься к олимпиаде или догоняешь пропущенное) — тогда лучше указать класс, к которому относится тема, а не свой. Или не указывать вовсе и написать в теле «я в 7-м, но тема 8-го».

## Три сортировки и как их использовать

В каждом разделе (предмет или предмет + класс) три вкладки:

| Сортировка | Что показывает | Кому |
|---|---|---|
| Свежие | Новые вопросы первыми | Тем, кто хочет отвечать: тут вопросы без разбора |
| Топ | По голосам | Тем, кто хочет читать лучшие разборы |
| Просмотры | Самые посещаемые | Тем, кто хочет увидеть типовые задачи: популярное = частое в контрольных |

Сценарий «за 20 минут до контрольной»: открыть свой предмет и класс → «просмотры» → пролистать 10–15 задач, читая только тему и идею решения. Это не заменит подготовку, но напомнит типы задач. Как готовиться по-настоящему — в статье [как готовиться к контрольной](/blog/kak-gotovitsya-k-kontrolnoj).

Сценарий «хочу репутацию»: свой сильный предмет → «свежие» → вопросы без принятого ответа → разбор. Как писать — в статье [как отвечать в Razbery](/blog/kak-otvechat-v-razbery).

## Как каталог помогает по разным предметам

Разные предметы — разные типы вопросов, и каталог это показывает:

- **Математика, физика, химия** — задачи с числовым ответом. Разбор: дано → формула → шаги → проверка. Здесь особенно важен класс.
- **Русский** — «почему пишется так», разборы слов и предложений. Класс менее важен, орфограмма одна на все классы.
- **Литература, история, обществознание** — вопросы «почему» и «в чём смысл». Разбор — тезис, аргументы, примеры. Голоса здесь показывают не «верно / неверно», а «убедительно / нет».
- **Английский** — грамматика с примерами, объяснение правила на 3–4 предложениях.
- **Информатика** — код и алгоритмы; Markdown позволяет вставить блок кода, KaTeX — формулы для систем счисления.

> **Пример:** ученик 8 класса не мог найти разбор задачи на «нагревание и плавление льда». Искал в математике — там задачи про лёд разве что про проценты. Переключил на физику, 8 класс, вкладка «просмотры» — третьим вопросом шла точно такая же задача с разбором через Q = cmΔt + λm. Пять минут вместо вечера.

## Если предмета нет в списке

Немецкого, французского, музыки, ИЗО, технологии в каталоге нет. Варианты:

- иностранные языки кроме английского — в «английский» с пометкой языка в заголовке: «[Немецкий] Порядок слов в придаточном»;
- астрономия — в физику;
- экономика, право — в обществознание;
- всё остальное — в ближайший по смыслу предмет с пометкой в заголовке.

Модерация не скроет вопрос за «не тот предмет», если он школьный и учебный. Скроет — за нешкольные темы вообще. Правила — в статье [что нельзя спрашивать и почему](/blog/razbery-moderaciya-i-pravila).

## Типичные ошибки

- **Ставить «математику» в 9 классе на уравнение.** Оно потеряется: математику смотрят в основном по 5–6 классам. Алгебра.
- **Класс «11», потому что ты в 11-м, а тема из 8-го.** Отвечающие подумают, что нужно решение уровня ЕГЭ. Укажи класс темы.
- **Химическую задачу — в математику, потому что «не получается посчитать».** Считать поможет химик, потому что ошибка обычно в молярной массе, а не в делении.
- **Не пользоваться сортировкой «просмотры» перед контрольной.** Это готовый список типовых задач по твоему классу, бесплатно и за 15 минут.
- **Искать в каталоге вместо поиска, когда знаешь тему.** Каталог — чтобы осмотреться; поиск — чтобы найти конкретное. Как искать — в статье [поиск по разборам](/blog/razbery-poisk-po-razboram).

## Частые вопросы

### Какие предметы есть в Razbery?

Пятнадцать: математика, алгебра, геометрия, физика, химия, биология, русский язык, литература, английский, история, обществознание, география, информатика, ОБЖ, окружающий мир. Классы — с 5 по 11, класс у вопроса необязателен.

### Математика или алгебра — что выбрать для вопроса?

5–6 класс — математика. 7–11 — алгебра для уравнений, функций, степеней; геометрия для фигур. «Математика» в старших классах — для олимпиадных и логических задач, которые не ложатся ни в алгебру, ни в геометрию.

### Нужно ли указывать класс в вопросе?

Не обязательно, но лучше указать: отвечающий объяснит на нужном уровне, а вопрос попадёт в фильтр по классу. Если тема из другого класса — укажи класс темы, а не свой.

### Где найти задачи по классам с решением?

В каталоге: `/qa/` → предмет → класс, вкладка «топ» или «просмотры». Там вопросы с разборами, отсортированные по оценкам и популярности. Для конкретной темы — поиск с фильтром по предмету и классу.

### Что делать, если моего предмета нет?

Выбрать ближайший (немецкий — в английский, астрономия — в физику, право — в обществознание) и написать реальный предмет в начале заголовка в квадратных скобках. Школьный учебный вопрос не скроют за «не тот предмет».
