За два дня до контрольной по алгебре ты открываешь тетрадь, чтобы повторить, и видишь: страницы с номерами задач без условий, решения без ответов, где-то зачёркнуто полстраницы, формулы разбросаны между примерами. Пять минут — и ты закрываешь тетрадь и открываешь учебник. Тетрадь оказалась бесполезной, хотя в ней 60 исписанных страниц.

Это самая частая ситуация. Тетрадь по математике у большинства — это место, куда сдают домашку. Но она может быть чем-то большим: **твоим личным учебником**, где формулы лежат в одном месте, типовые задачи размечены, а ошибки собраны и объяснены. Такая тетрадь заменяет репетитора при подготовке к контрольной — по ней видно, что ты знаешь, что нет и где именно спотыкаешься.

Ниже — конкретная система: как разделить тетрадь на зоны, как оформлять решение, чтобы его можно было прочитать через месяц, что делать с ошибками и как всё это не превратить в оформительство вместо математики.

## Три зоны тетради

Одна тетрадь на 96 листов (или две по 48) делится на три части. Не физически — просто резервируешь страницы.

| Зона | Где | Что там | Сколько страниц |
|---|---|---|---|
| Рабочая | Начало и основная часть | Классная и домашняя работа по порядку | 70–80 % |
| Справочник | Последние 8–10 листов | Формулы, правила, алгоритмы — по темам | 10–15 % |
| Ошибки | 3–4 листа перед справочником | Задачи, в которых ошибся, с разбором | 5–10 % |

Почему именно так: справочник и ошибки — это то, что нужно перед контрольной. Они лежат в одном известном месте, а не рассыпаны по рабочим страницам. Открыл конец тетради — и вся подготовка перед глазами.

Если учитель требует сдавать тетрадь на проверку и не одобряет «лишние» записи — заведи вторую тонкую тетрадь под справочник и ошибки. Главное, чтобы они существовали.

## Рабочая зона: как оформлять решение

Решение задачи через месяц должен понять человек, который не помнит, что это была за задача. Этим человеком будешь ты.

### Правила записи

1. **Дата и тема** — в начале каждого урока. Не «Классная работа», а «Классная работа. Квадратные уравнения. Теорема Виета». По теме потом найдёшь.
2. **Номер и краткое условие.** Не переписывай задачу целиком, но «№ 214: найти корни x² − 5x + 6 = 0» — обязательно. Без условия решение бесполезно.
3. **Ход решения с пояснениями.** Не только выкладки, а слова между ними: «по теореме Виета», «выносим общий множитель», «делим обе части на 2». Учитель не требует — пиши для себя.
4. **Ответ выделен.** Рамкой, подчёркиванием, словом «Ответ:». Чтобы глаз находил за секунду.
5. **Пометка о результате.** После проверки: ✓ — верно; ✗ — ошибка (и стрелка в зону ошибок); ? — решил, но не понял почему.

### Как выглядит хорошая запись

```
12.10. Кл. работа. Квадратные уравнения. Теорема Виета.

№ 214 (б). Решить: x² − 5x + 6 = 0
  По Виета: x₁ + x₂ = 5, x₁·x₂ = 6
  Подбираем: 2 и 3 (2+3=5, 2·3=6) ✓
  Ответ: x₁ = 2, x₂ = 3

№ 215 (а). Решить: 2x² − 7x + 3 = 0
  Виета не подходит (a ≠ 1) → через дискриминант
  D = b² − 4ac = 49 − 24 = 25, √D = 5
  x = (7 ± 5) / 4 → x₁ = 3, x₂ = 1/2
  Ответ: 3; 0,5
  ✗ было: забыл разделить на 2a, написал x = 7 ± 5 → см. Ошибки, с. 90
```

Пояснение «Виета не подходит (a ≠ 1)» — самое ценное в этой записи. Через месяц ты не вспомнишь, почему выбрал дискриминант, а тут написано.

> **Совет:** оставляй поля справа шириной 3–4 см. Туда идут пометки при повторении: «важно», «не понял», «повторить», ссылка на страницу справочника. Поля нужны, даже если учитель их не требует.

## Справочник: формулы и алгоритмы по темам

Это конец тетради, и это самое важное место. Каждая пройденная тема получает полстраницы–страницу:

**Название темы** → **формулы** → **когда применять** → **типовая ловушка**.

Пример страницы справочника:

```
КВАДРАТНЫЕ УРАВНЕНИЯ  ax² + bx + c = 0

D = b² − 4ac
  D > 0 → 2 корня: x = (−b ± √D) / 2a
  D = 0 → 1 корень: x = −b / 2a
  D < 0 → корней нет

Виета (только при a = 1!): x₁ + x₂ = −b, x₁·x₂ = c
Неполные: ax² + bx = 0 → x(ax + b) = 0 → x = 0 или x = −b/a ;  ax² + c = 0 → x² = −c/a (если −c/a ≥ 0)
Разложение: ax² + bx + c = a(x − x₁)(x − x₂)

Ловушки:
  • знак b в Виета: сумма = −b, не b
  • делить на 2a, а не на 2
  • D = 0 — один корень, не «нет корней»
```

Блок «Ловушки» — это не из учебника, это из твоих собственных ошибок. Он делает справочник личным и в десять раз полезнее любой готовой таблицы формул.

Заполнять справочник — в день, когда тема закончена, 10 минут. Не откладывать «на выходные»: через неделю уже не вспомнишь, что было непонятно.

## Зона ошибок: что писать и зачем

Каждая ошибка в контрольной или домашке — это подсказка, где ты споткнёшься снова. Если её не записать, ты споткнёшься.

Формат записи — три строки:

1. **Задача** (кратко) и **что я сделал не так**.
2. **Как правильно** и **почему**.
3. **Тип ошибки**: невнимательность / не знал формулу / не понял метод / арифметика.

```
с. 90. ОШИБКИ

1. 2x² − 7x + 3 = 0. Написал x = 7 ± 5, забыл /2a.
   Правильно: (7 ± 5)/4. Формула корней — ВСЕГДА со знаменателем 2a.
   Тип: не знал формулу точно → повторил, добавил в справочник.

2. (x − 3)² = x² − 9. Ошибка!
   Правильно: x² − 6x + 9. Квадрат разности ≠ разность квадратов.
   Тип: путаю формулы → карточка.

3. Задача на движение: скорость 60 км/ч, время 1 ч 30 мин, S = 60·1,3 = 78.
   Правильно: 1 ч 30 мин = 1,5 ч → S = 90 км.
   Тип: перевод единиц → всегда переводить минуты в доли часа.
```

Тип ошибки — самое важное. Если из десяти ошибок семь — «невнимательность», проблема не в математике, а в том, что ты не проверяешь. Если пять — «не понял метод», надо разбирать тему заново, а не решать больше задач. Про подход к разбору ошибок — в [статье про то, как разбирать ошибки в домашке](/blog/oshibki-v-domashke-kak-razbirat).

> **Пример:** Полина в 8 классе завела зону ошибок после трёх троек подряд. Через месяц там было 23 записи. Она посмотрела на типы: 14 — «арифметика и знаки», 6 — «формула», 3 — «метод». Вывод очевидный: проблема не в понимании, а в аккуратности. Она стала проверять каждое действие с конца и подписывать знаки при переносе. Следующая контрольная — четыре, потом пять. Математику она не «подтянула» — она просто перестала терять баллы на ерунде.

## Как готовиться к контрольной по своей тетради

Когда система есть, подготовка к контрольной — это не «перечитать всё», а три коротких шага:

1. **Справочник по теме** (5 минут): перечитать формулы и ловушки. Закрыть, написать по памяти на черновике. Что не воспроизвёл — повторить.
2. **Зона ошибок** (10 минут): перерешать все задачи по теме, в которых ошибался. Именно их, не новые. Если снова ошибся — это твоя главная тема на сегодня.
3. **Рабочая зона** (15 минут): найти по датам и темам классные работы с пометкой «?» — то, что решил, но не понял. Разобрать: по учебнику, у одноклассника или [задать вопрос с разбором](/qa/).

Полчаса вместо трёх — и подготовка точечная, а не «всё подряд». Про подготовку к контрольной по разным срокам — в [отдельной статье](/blog/kak-gotovitsya-k-kontrolnoj).

## Тетрадь по геометрии: особенности

Геометрия требует того же, но с двумя добавками:

- **Чертёж — обязательно и крупно.** Треть страницы, не уголок. С обозначениями всех точек и данных (равные отрезки — штрихами, прямые углы — квадратиком, данные величины — прямо на чертеже). Плохой чертёж — половина ошибок в геометрии.
- **Справочник — с рисунками.** Не «сумма углов треугольника 180°», а рисунок треугольника с подписью. Теоремы запоминаются вместе с картинкой. Про заучивание теорем — в [статье про теоремы и доказательства](/blog/kak-uchit-teoremy).

Отдельная страница справочника по геометрии — «Признаки»: равенства треугольников (три), подобия (три), параллельности прямых, параллелограмма. Их спрашивают на каждой контрольной и все путают.

## Типичные ошибки

- **Писать только выкладки, без слов.** Через неделю ты не поймёшь, что и зачем делал.
- **Не записывать условие.** Решение без условия — набор цифр.
- **Зачёркивать до нечитаемости.** Ошибка — это информация. Аккуратно зачеркни одной чертой, чтобы видеть, что было не так.
- **Справочник «потом».** Потом = никогда. Заполняй в день, когда тема закрыта.
- **Переписывать формулы из учебника.** Справочник ценен ловушками и «когда применять», а не формулами — они есть в учебнике.
- **Не отмечать результат проверки.** Без ✓/✗/? ты не знаешь, что из решённого верно.
- **Тратить час на оформление.** Цветные ручки, линейка под каждой формулой, заголовки трёх размеров — это не учёба. Один цвет для решений, один для выделений, всё.

## Частые вопросы

### Как правильно вести тетрадь по математике?

Раздели на три зоны: рабочая (классная и домашняя по порядку, с датой, темой, условием и пояснениями), справочник в конце (формулы, «когда применять», ловушки по темам) и страница ошибок (что не так, как правильно, тип ошибки). Пометки ✓/✗/? после проверки. Такая тетрадь готовит к контрольной за полчаса.

### Что писать в тетради, если учитель проверяет оформление?

Оформляй рабочую зону по требованиям учителя — это не мешает системе. Пояснения к шагам можно писать на полях или карандашом. Справочник и ошибки, если учитель против «лишнего» в тетради, веди во второй тонкой тетради — главное, чтобы они были.

### Нужно ли переписывать решения начисто?

Нет, если учитель не требует. Переписывание не учит — ты копируешь, а не думаешь. Лучше потрать эти 20 минут на разбор ошибки или заполнение справочника. Аккуратно зачёркнутая ошибка полезнее чистовика.

### Как вести тетрадь по алгебре в 10–11 классе для ЕГЭ?

Так же, плюс: справочник разбить по типам заданий ЕГЭ («производная — что нужно», «тригонометрия — формулы», «стереометрия — что доказывать»), а зону ошибок вести по каждому пробному варианту с указанием номера задания. К весне будет видно, какие задания стабильно проваливаются. План подготовки — в [статье про профильную математику](/blog/ege-profilnaya-matematika-plan).
