# Уведомление в Роскомнадзор: как подать и что писать

Черновик заполнения для getdoday.ru. Значения собраны по коду — что
приложение действительно хранит, а не что «обычно пишут».

Оговорка: я не юрист. Формулировки ниже — рабочая заготовка, а не
юридическое заключение. Перед отправкой перечитай своими глазами: за
недостоверные сведения в уведомлении отвечает оператор, то есть ты.

---

## Как подать

Три способа, выбирай любой:

1. **Через сайт РКН, с подтверждением через Госуслуги.** <https://pd.rkn.gov.ru/>
   → «Формы электронных документов» → «Уведомление об обработке персональных
   данных». Заполняешь форму, подписываешь входом через ЕСИА. Самый простой
   путь для физлица без электронной подписи.
2. **Электронно с УКЭП** — если квалифицированная подпись уже есть.
3. **На бумаге** — распечатать заполненную форму, подписать и отправить почтой
   в территориальное управление РКН по своему региону.

Уведомление подаётся **до начала обработки**. Сайт уже работает, так что
тянуть не стоит: по ч. 10 ст. 13.11 КоАП за неподачу штраф для гражданина —
от 5 до 10 тысяч рублей.

Ответ приходит в течение 30 дней, после чего оператор появляется в реестре
на портале РКН.

---

## Форма на pd.rkn.gov.ru — по полям

Порядок полей — как в форме. Где написано «отметить», это чекбоксы.

### Сведения об операторе

| Поле | Что ставить |
|---|---|
| Регион оператора | свой (в форме на скриншоте — Московская область) |
| Тип оператора | **Физическое лицо** |
| Фамилия, имя, отчество | свои, как в паспорте |
| Документ, удостоверяющий личность | Паспорт гражданина РФ; серия, номер, кем выдан, дата выдачи |
| СНИЛС, ИНН | свои |
| Адрес оператора | адрес регистрации с индексом |
| Почтовый адрес | тот же, если письма приходят туда же |
| Телефон, электронная почта | рабочие, по ним будут связываться |
| Регионы обработки | свой регион — сервер и ты находитесь в РФ |

**Важно про возраст.** Форма требует паспорт и СНИЛС, а оператор отвечает по
закону лично. Если тебе нет 18, оператором логичнее указывать родителя — он и
подписывает, и отвечает. Это стоит обсудить дома до подачи, а не после.

### Цель обработки ПД

> Предоставление доступа к сервису планирования учебных задач и напоминаний,
> регистрация и аутентификация пользователей, обратная связь с пользователями,
> приём платежей за платные тарифы.

### Категории персональных данных — отметить

- фамилия, имя, отчество *(имя пользователи указывают сами — необязательно)*;
- адрес электронной почты;
- номер контактного телефона *(его оставляют клиенты при записи в Lessio)*;
- иные персональные данные — а в пояснении написать: содержимое задач и
  заметок пользователя, данные школьного дневника, IP-адрес.

Всё остальное — **не отмечать**: ни паспорт, ни СНИЛС, ни ИНН, ни адрес, ни
данные о здоровье. Ты их не собираешь.

### Специальные категории ПД

**Не отмечать ничего.** Раса, политические взгляды, здоровье, судимость — не
обрабатываются.

### Биометрические ПД

**Не отмечать.** Фотографий и отпечатков нет.

### Категории субъектов — отметить

- **Клиенты** (пользователи сервиса);
- **Пользователи сайта**, если такой пункт есть отдельно.

Работников, соискателей и контрагентов не отмечать — их нет.

### Правовое основание — отметить

- обработка с **согласия субъекта** персональных данных;
- обработка для **исполнения договора**, стороной которого является субъект
  (у тебя это оферта на оказание услуг сервиса).

Всё остальное из длинного списка (госорганы, судебные акты, реестры) — мимо.

### Перечень действий — отметить

сбор · запись · систематизация · накопление · хранение · уточнение
(обновление, изменение) · извлечение · использование · блокирование ·
удаление · уничтожение

Передачу отмечать **не надо**, если не передаёшь данные третьим лицам.

### Способы обработки

**Смешанная, без передачи по сети Интернет** — не подходит, у тебя сайт.
Ставь: **смешанная, с передачей по сети Интернет**.

### Описание мер (ст. 18.1 и 19)

> Назначено лицо, ответственное за организацию обработки персональных данных.
> Приняты и опубликованы политика обработки персональных данных и правила
> её реализации. Осуществляется внутренний контроль соответствия обработки
> требованиям закона. Работники (при их появлении) знакомятся с положениями
> законодательства. Обеспечивается неограниченный доступ к политике на сайте.

### Средства обеспечения безопасности

> Доступ к данным разграничен: пользователь получает только свои данные.
> Пароли хранятся в виде хеша (argon2id), в открытом виде не сохраняются.
> Соединение защищено TLS. Токены доступа к внешним сервисам и ключи
> шифруются при хранении. Ведётся резервное копирование. Применяются защита
> от автоматической регистрации, ограничение частоты запросов, отзыв сессий
> при смене пароля и заголовки безопасности браузера.

### Криптографические средства

Ставь: **не используются** — сертифицированных средств криптозащиты у тебя
нет, а TLS и шифрование в базе к ним не относятся.

### Дата начала обработки

Дата, когда появились первые зарегистрированные пользователи.

### Срок или условие прекращения

> Достижение целей обработки, отзыв согласия субъекта либо удаление учётной
> записи пользователем.

### Трансграничная передача

**Нет.** После сегодняшней правки зарубежных провайдеров ИИ в сервисе не
осталось, данные за границу не уходят.

### Сведения о местонахождении базы данных

| Поле | Значение |
|---|---|
| Страна | Российская Федерация |
| Адрес ЦОД | адрес дата-центра хостера — спроси в поддержке хостинга |
| Собственник ЦОД | название хостинг-провайдера |

### Ответственный за организацию обработки

ФИО оператора (или родителя, если оператор — он), должность оставить пустой
или написать «оператор — физическое лицо», контакты те же.

## Справка: что именно хранит приложение

Собрано по коду — на случай вопросов и для политики на сайте.

| Данные | Где | Зачем |
|---|---|---|
| Адрес электронной почты | `users.email` | вход, письма подтверждения и напоминаний |
| Хеш пароля | `users.password_hash` | аутентификация (argon2id, сам пароль не хранится) |
| IP-адрес и подсеть регистрации | `users.signup_ip`, `users.signup_subnet` | защита от массовой автоматической регистрации |
| Telegram user id и chat id | `telegram_links` | вход через Telegram и бот-уведомления |
| Содержимое задач, заметок, привычек, настроения | таблицы задач и смежные | сам сервис |
| Данные школьного дневника (домашние задания, расписание) | `school_integrations`, задачи | синхронизация с МЭШ и Школьным порталом МО, только по явному подключению |
| Токен доступа к школьному порталу | `school_integrations.auth_token` | там же; хранится в зашифрованном виде |
| Имя, почта и телефон клиента репетитора | `lessio_bookings`, `lessio_clients` | запись на занятие |
| Идентификатор платежа провайдера | таблицы биллинга | подтверждение оплаты; реквизиты карт не хранятся |
| Переписка с ИИ-помощником | `ai_messages` | история диалога, видна только самому пользователю |

**Специальные категории** (здоровье, национальность, политические взгляды) и
**биометрия** — не обрабатываются. Так и указывай.

## Что проверить на сайте до подачи

1. **Политика обработки персональных данных** — есть на `/privacy`.
   Перечитай: она должна совпадать с тем, что напишешь в уведомлении.
2. **Согласие при регистрации** — галочка есть и без неё регистрация не
   проходит.
3. **Удаление аккаунта** — работает из профиля.
4. **Ответственное лицо** — в политике должно быть указано, к кому обращаться
   по вопросам обработки: адрес почты для запросов субъектов.

Если хочешь — соберу отдельным файлом текст согласия и проверю политику на
`/privacy` на соответствие тому, что реально собирается. Скажи.
