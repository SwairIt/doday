# ИИ-помощник в Doday: дизайн

Дата: 2026-08-26. Статус: утверждён владельцем, готов к планированию реализации.

## Зачем

У школьника, который открыл задачу «Алгебра № 214», нет быстрого способа спросить
«а что тут вообще значит это слово». Он уходит в браузер, теряет контекст и время.
Идея: чат с моделью прямо внутри Doday, с автоподстановкой контекста задачи и
готовыми шаблонами вопросов, чтобы не формулировать с нуля.

Позиционирование на сайте — «спроси, если что-то непонятно». Технических
ограничений на характер вопросов не накладываем: что делать с ответом, решает
школьник. Это осознанное решение владельца.

## Границы

**Делаем:** чат с историей, вход из задачи и отдельной страницей, шаблоны
промптов, подключение своего ключа, стриминг ответа, лимиты, фильтры, age gate.

**Не делаем:** свой ключ для всех за счёт владельца (пользователь приносит свой);
инструкции по подключению Gemini (его условия запрещают сервисы для аудитории
младше 18 — цитата в разделе «Правовые требования»); распознавание фото задач;
голосовой ввод; автоматическое решение задач без участия пользователя.

## Что видит пользователь

### Вход в чат

1. **Из задачи.** В панели деталей (`app/templates/_partials/task_detail.html`)
   — кнопка «Спросить ИИ». Открывает чат, в контекст автоматически уходит
   название задачи, её описание, предмет (если задача из школьного проекта) и
   срок. Пользователь сразу пишет вопрос, не повторяя условие.
2. **Отдельная страница** `/app/ai` — свободный разговор без привязки к задаче.
   Пункт в сайдбаре приложения.

### Первый вход: экран согласия

Показывается один раз, состояние хранится в `users.ai_terms_accepted_at`.

Текст:
- сервисом ИИ можно пользоваться с 18 лет;
- ответы генерирует нейросеть, они могут содержать ошибки — проверяй важное;
- не вводи настоящие имя, фамилию, школу, класс и адрес;
- запросы уходят провайдеру, чей ключ подключён.

Одна кнопка «Принять». Без принятия чат не открывается.

### Экран чата

- лента сообщений, ответ печатается по мере генерации;
- под каждым ответом модели — пометка «Сгенерировано ИИ» (договорное требование
  провайдеров);
- поле ввода, отправка по Enter, Shift+Enter — перенос строки;
- над полем — горизонтальная лента чипов-шаблонов;
- кнопка «Стоп» во время генерации;
- счётчик оставшихся запросов на сегодня.

### Шаблоны промптов

Лежат в `app/ai/prompts.py` как список кортежей `(ярлык, текст)`. Нажатие
подставляет текст в поле ввода, курсор в конец — пользователь дописывает своё.

Стартовый набор:

| Ярлык | Подставляемый текст |
|---|---|
| Объясни просто | «Объясни простыми словами, как будто мне 12 лет: » |
| По шагам | «Разбери по шагам, объясняя каждый переход: » |
| Проверь решение | «Проверь моё решение и укажи, где ошибка:\n» |
| Что значит слово | «Что означает термин » |
| В пределах 200 слов | «Ответь в пределах 200 слов: » |
| План сочинения | «Составь план сочинения по теме: » |
| Как запомнить | «Придумай, как запомнить: » |

## Данные

### `ai_credentials` — ключи пользователей

| Поле | Тип | Комментарий |
|---|---|---|
| `id` | UUID PK | |
| `user_id` | UUID FK users, CASCADE, unique | один ключ на пользователя |
| `provider` | str(32) | `cloudru`, `mistral`, `custom` |
| `base_url` | str(255) | для `custom`; иначе из справочника |
| `model` | str(128) | выбранная модель |
| `key_ciphertext` | text | Fernet |
| `key_version` | int | для ротации ключа шифрования |
| `key_last4` | str(8) | показываем в интерфейсе вместо ключа |
| `created_at`, `updated_at` | timestamptz | |

Ключ в открытом виде не возвращается никогда — ни в API, ни в шаблон.

### `ai_messages` — история

| Поле | Тип | Комментарий |
|---|---|---|
| `id` | UUID PK | |
| `user_id` | UUID FK users, CASCADE, index | |
| `task_id` | UUID FK tasks, SET NULL, nullable | если чат открыт из задачи |
| `role` | str(16) | `user` / `assistant` |
| `content` | text | |
| `tokens_in`, `tokens_out` | int nullable | для статистики и лимитов |
| `created_at` | timestamptz, index | |

Диалог = сообщения одного `user_id` с одним `task_id` (или без него),
упорядоченные по времени. Отдельной сущности «беседа» не заводим — YAGNI.

### `ai_usage_daily` — лимиты

| Поле | Тип |
|---|---|
| `user_id` | UUID FK users, CASCADE |
| `day` | date |
| `requests` | int |

Первичный ключ `(user_id, day)`. **В Postgres, не в памяти** — деплой
перезапускает процесс на каждый пуш, счётчик в памяти обнулялся бы.

### Поле в `users`

`ai_terms_accepted_at: timestamptz | None` — согласие с условиями чата.

## Провайдерный слой

Один модуль `app/ai/provider.py` поверх OpenAI-совместимого протокола. Своя
обёртка на httpx (~40 строк), без сторонних мультипровайдерных библиотек:
они тянут десятки зависимостей и пинят версии `openai`, что конфликтует с
проектом.

```python
async def stream_completion(
    *, base_url: str, api_key: str, model: str,
    messages: list[Message], max_tokens: int,
) -> AsyncIterator[str]:
    """Отдаёт куски текста по мере генерации. Ошибки → AiProviderError."""
```

Справочник провайдеров — `app/ai/providers.py`:

| Ключ | Название | base_url | Модель по умолчанию |
|---|---|---|---|
| `cloudru` | Cloud.ru | `https://foundation-models.api.cloud.ru/v1` | внутренняя дешёвая |
| `mistral` | Mistral | `https://api.mistral.ai/v1` | Ministral |
| `custom` | Другой (OpenAI-совместимый) | вводит пользователь | вводит пользователь |

Конкретные модели и их доступность проверяются перед реализацией — данные
исследования по провайдерам частично оказались недостоверными и требуют
повторной проверки в свежей сессии.

## Стриминг

FastAPI 0.115 (нативного SSE нет) → `StreamingResponse` с `media_type`
`text/event-stream`. Эндпоинт `POST /api/ai/stream` (браузерный `EventSource`
умеет только GET, поэтому читаем поток через `fetch` + `ReadableStream`).

Заголовки ответа: `Cache-Control: no-cache`, `X-Accel-Buffering: no`,
`Connection: keep-alive`.

Обрыв соединения: `try/finally` вокруг вызова провайдера, чтобы закрыть
upstream — иначе токены продолжат тратиться после ухода пользователя.

`nginx` (`deploy/nginx.conf`) — отдельный location:

```nginx
location /api/ai/stream {
    proxy_pass http://127.0.0.1:8011;
    proxy_http_version 1.1;
    proxy_set_header Connection "";
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 3600s;
    send_timeout 3600s;
}
```

Без этого поток обрывается на 60-й секунде и буферизуется целиком.

## Безопасность

**Шифрование ключей.** Переиспользуем подход из
`app/lessio/google_calendar.py:37-48` — PBKDF2(100k итераций) от
`APP_SECRET_KEY` + Fernet. Отличия: своя соль (`b"doday-ai-key-v1"`) и поле
`key_version` в таблице, чтобы можно было перевыпустить ключ шифрования без
потери данных.

**Лимиты.** По умолчанию 50 запросов в сутки на пользователя (настраивается).
Проверка до обращения к провайдеру. Ответ 429 с понятным текстом и временем
сброса.

**Размеры.** Промпт ≤ 4000 символов, история в контексте ≤ 20 последних
сообщений, `max_tokens` ответа ≤ 2000.

**Персональные данные.** Перед отправкой промпт проверяется простыми
эвристиками (похоже на ФИО, телефон, адрес) — при срабатывании показываем
предупреждение и просим переформулировать. Это не блокировка, а подсказка:
надёжно вычистить ПДн регулярками невозможно, поэтому основная защита —
предупреждение в интерфейсе.

**Фильтр ответов.** Проверка ответа модели на темы, запрещённые к
распространению среди детей (ст. 5 ч. 2 436-ФЗ): суицид и самоповреждение,
наркотики и алкоголь, оправдание насилия, порнография, нецензурная брань.
При срабатывании ответ не показывается, вместо него — сообщение с
предложением переформулировать вопрос.

**Рендеринг.** Ответ модели — markdown, рендерится тем же путём, что и Q&A
(`app/qa/rendering.py`): markdown-it с `html: False` + санитайзер. Прямая
вставка HTML от модели исключена.

## Правовые требования

Проверенные факты, влияющие на реализацию:

1. **Пометка «сгенерировано ИИ»** под каждым ответом — договорное требование
   провайдеров (Cloud.ru: п. 4.9 приложения к оферте).
2. **Gemini не используем и не рекомендуем.** Дословно из его условий:
   «You also will not use the Services as part of a website, application, or
   other service … that is directed towards or is likely to be accessed by
   individuals under the age of 18». Doday — сервис для школьников. Технически
   API из России доступен (проверено), но условия нарушать не будем; при
   нарушении Google блокирует аккаунт владельца ключа, то есть пользователя.
3. **Уведомление Роскомнадзора** об обработке персональных данных — отдельная
   задача владельца, не блокирует эту фичу, но должна быть закрыта.
4. **Age gate 18+** — экран согласия при первом входе.

## Ошибки

| Ситуация | Поведение |
|---|---|
| Ключ не подключён | Экран «подключи ключ» со списком провайдеров и инструкциями |
| Ключ неверный (401 от провайдера) | «Ключ не принят провайдером, проверь его в настройках» |
| Превышен лимит провайдера (429) | «Провайдер ограничил частоту запросов, попробуй через минуту» |
| Нет денег на счету провайдера (402) | «На счету провайдера закончились средства» |
| Наш суточный лимит | 429 + время сброса |
| Провайдер недоступен | «Провайдер не отвечает, попробуй позже», запись в лог |
| Пользователь ушёл со страницы | Закрываем upstream в `finally` |

Ключ пользователя никогда не попадает в логи и в текст ошибок.

## Тестирование

Без реальных обращений к провайдеру — подменяем `stream_completion`.

- шифрование ключа туда-обратно, `key_last4` совпадает, открытый ключ не
  возвращается из API и не встречается в HTML;
- лимит: 51-й запрос за сутки → 429; счётчик переживает «перезапуск»
  (пересоздание сессии);
- чат: сообщение сохраняется, история отдаётся в правильном порядке, контекст
  задачи подставляется;
- стриминг: эндпоинт отдаёт `text/event-stream`, куски приходят по мере
  генерации, при обрыве вызывается закрытие upstream;
- фильтр: ответ с запрещённой темой не показывается;
- age gate: без согласия чат недоступен, после согласия открывается;
- шаблоны: все отрендерены на странице.

## Этапы

1. **Ключи и провайдеры.** Таблица `ai_credentials`, шифрование, экран
   настроек, справочник провайдеров, проверка ключа кнопкой «Проверить».
2. **Чат и стриминг.** Таблицы `ai_messages`, `ai_usage_daily`, эндпоинты,
   страница `/app/ai`, age gate, nginx.
3. **Интеграция в задачи.** Кнопка в панели задачи, подстановка контекста,
   шаблоны промптов.

Каждый этап — отдельный план и отдельная порция тестов.
