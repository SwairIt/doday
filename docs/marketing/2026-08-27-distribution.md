## 1. Хабр — первым и без спешки

Хабы (ставить все пять, они по делу):

**Информационная безопасность** · **Python** · **FastAPI** · **Поисковая оптимизация** · **Разработка веб-сайтов**

Теги (через запятую, ровно так):

```
информационная безопасность, боты, антибот, xss, idor, ssrf, x-forwarded-for,
fastapi, python, sse, streaming, sqlalchemy, postgresql, htmx, alpine.js,
llm, ии-помощник, openai api, seo, семантическое ядро, персональные данные,
152-фз, pet-project, indie hacker, doday, getdoday
```

Что учесть из прошлой модерации (по ней уже прилетало):

- **Никакой автобиографии и возраста.** В прошлый раз модератор снял статью именно за это. Имя автора — можно и нужно, возраст и «я школьник» — нет.
- **Обращение на «вы»** по всему тексту. В черновике так и написано.
- **Код — обычными блоками**, не картинками. Все сниппеты уже готовы к копированию.
- **Ссылка на GitHub — отдельной заметной строкой**, а не спрятана в слове.
- **Финал** — «Спасибо, что дочитали».
- Указание, что текст пишется в паре с ИИ-агентом, оставить: Хабр требует раскрывать это, и в статье такой абзац есть.

## 2. Русскоязычные площадки

Один и тот же текст веером — это спам, и его так и воспримут. Каждой площадке нужен свой заход: разное вступление, разная длина, разные акценты.

| Площадка | Что публиковать | Акцент |
|---|---|---|
| **vc.ru**, раздел «Разработка» | Сокращённая версия, 40% объёма | Продуктовая история: боты пришли — что я потерял и что починил |
| **DTF**, «Гейминг/Инди» | Не подходит, пропустить | — |
| **Пикабу**, «Информационная безопасность» | Только часть про ботов и подделку IP | Драма и цифры, минимум кода |
| **Хабр Q&A** | Не постить статью. Отвечать на вопросы про `X-Forwarded-For` со ссылкой | Экспертность, не реклама |
| **Telegram-каналы** про Python и инди-разработку | Анонс на 3–4 абзаца + ссылка | Одна яркая находка на канал |
| **Тематические чаты** (Python, FastAPI) | Ссылку кидать только если спросили про SSE или антибот | Иначе прилетит бан |

## 3. Англоязычные площадки

| Площадка | Формат | Заголовок |
|---|---|---|
| **dev.to** | Полный английский текст | `176 bots, an AI assistant on the user's own key, and 334 articles` |
| **Hacker News** | Ссылка на dev.to, не Show HN | `Your IP rate limit is one header away from useless` — самая сильная находка выносится в заголовок |
| **Lobste.rs** | Ссылка, теги `security`, `python`, `web` | То же |
| **r/Python** | Полный текст, без ссылок в первом абзаце | Часть про SSE и async-генератор |
| **r/webdev** | Сокращённо | XSS через JSON-LD |
| **r/netsec** | Только часть 1–2, строго технически | Подделка `X-Forwarded-For` и IDOR |
| **r/SideProject**, **Indie Hackers** | Продуктовая история | Как пет-проект дорос до аудита |
| **Hashnode**, **Medium** | Кросс-пост с канонической ссылкой на dev.to | — |

Правила, которые экономят от банов:

1. На Reddit сначала неделя обычных комментариев, потом пост. Свежий аккаунт со ссылкой = удаление.
2. Везде указывайте, что вы автор проекта. Скрытая реклама выходит дороже.
3. Кросс-посты — с `rel=canonical` на первую публикацию, иначе поисковик выберет копию.

## 4. Чтобы поисковик связал имя с продуктами

Уже сделано в коде:

- на витрине `all.getdoday.ru` — разметка `Person`: имя, альтернативные написания (`Yaroslav Boev`, `SwairIt`), `sameAs` на GitHub и оба домена;
- на лендинге `getdoday.ru` — `founder` и `author` у организации, `sameAs` на GitHub;
- обе страницы валидны по schema.org (проверено разбором JSON).

Что стоит сделать руками — по убыванию отдачи:

1. **GitHub-профиль.** Создать репозиторий `SwairIt/SwairIt` — его README показывается на странице профиля. Черновик готов: `docs/marketing/github-profile-readme.md`. Указать полное имя в настройках профиля и ссылки на оба домена.
2. **Профиль на Хабре.** Полное имя, ссылка на `getdoday.ru`, ссылка на GitHub. Хабр отлично индексируется — профиль часто попадает в выдачу по имени.
3. **Одинаковое написание везде.** «Ярослав Боев» и «Yaroslav Boev», без вариантов вроде «Ярик» и «Boev Y.». Поисковику нужен один устойчивый вариант, чтобы склеить сущности.
4. **Взаимные ссылки.** Статья ссылается на сайт, сайт — на GitHub, GitHub — на сайт и статью. Это и есть то, из чего собирается «граф знаний».
5. **Про запросы вида «туду-лист от школьника».** Тут скажу честно: на Хабре такое подавать нельзя, за это уже снимали. Но никто не мешает написать это на своём сайте — в разделе «о проекте» на витрине. Свой домен, свои правила, и индексируется он так же.
