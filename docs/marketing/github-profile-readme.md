2. **Bio:** «Делаю веб-продукты в одиночку. Python, FastAPI. getdoday.ru».
3. **Website:** `https://getdoday.ru/`.
4. **Закрепить репозитории** (Pin): `doday` первым.
5. В описании репозитория `doday` — одна строка по-английски, её видно в
   поиске GitHub: `Planner for students: homework from school diary,
   schedule, Telegram reminders. FastAPI + HTMX monolith.`

Смысл всего этого — чтобы имя, ник и домены встречались вместе на
страницах, которые хорошо индексируются. Тогда поисковик связывает их в
одну сущность, и по имени начинает находиться проект, а по проекту — имя.
