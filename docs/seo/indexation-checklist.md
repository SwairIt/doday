# Индексация getdoday.ru: что нажать, по шагам

Инструкция под этот сервер. Всё, что можно было сделать кодом, уже сделано —
ниже только то, что требует твоих рук: подтвердить права в вебмастерах и
включить push-уведомления поисковикам.

Времени на всё: ~30 минут.

## Где на сервере лежит `.env`

```
/var/www/getdoday/data/www/getdoday.ru/app/.env
```

**Способ 1 — FastPanel (проще).** Открыть <http://192.168.33.3/> → «Файловый
менеджер» → пройти по пути выше → правый клик на `.env` → «Редактировать» →
дописать строку → «Сохранить».

**Способ 2 — SSH.**
```bash
nano /var/www/getdoday/data/www/getdoday.ru/app/.env
```

**Применить изменения `.env`** (после каждой правки):
```bash
bash /var/www/getdoday/data/www/getdoday.ru/app/scripts/deploy.sh
```
Скрипт перезапустит uvicorn и проверит, что сайт отвечает 200.

## Шаг 1. Яндекс.Вебмастер — главное для России

1. Открыть <https://webmaster.yandex.ru/sites/add/>
2. В поле вписать `https://getdoday.ru` → кнопка **«Добавить»**
3. Откроется страница «Права на управление сайтом». Выбрать вкладку **«Мета-тег»**
4. Там будет строка вида:
   ```html
   <meta name="yandex-verification" content="a1b2c3d4e5f67890" />
   ```
   Скопировать **только то, что внутри `content`** → `a1b2c3d4e5f67890`
5. В `.env` на сервере дописать:
   ```
   YANDEX_VERIFICATION=a1b2c3d4e5f67890
   ```
6. Применить: `bash /var/www/getdoday/data/www/getdoday.ru/app/scripts/deploy.sh`
7. Вернуться в Вебмастер → кнопка **«Проверить»**. Должно стать «Права подтверждены»
8. Слева меню **«Индексирование» → «Файлы Sitemap»** → поле «Добавить файл Sitemap»,
   вставлять по одному и жать «Добавить»:
   ```
   https://getdoday.ru/sitemap.xml
   https://getdoday.ru/blog/sitemap.xml
   https://getdoday.ru/qa/sitemap.xml
   https://getdoday.ru/pdd/sitemap.xml
   ```
9. Слева **«Индексирование» → «Переобход страниц»** → вставить самые важные адреса
   (лимит ~20–30 в сутки, остальное поисковик возьмёт из sitemap):
   ```
   https://getdoday.ru/
   https://getdoday.ru/blog
   https://getdoday.ru/for-students
   https://getdoday.ru/qa/
   https://getdoday.ru/blog/kak-bystro-sdelat-domashnee-zadanie
   https://getdoday.ru/blog/kak-doday-uskoryaet-domashku
   https://getdoday.ru/blog/kak-podgotovitsya-k-ege-s-nulya
   https://getdoday.ru/blog/rebenok-ne-hochet-delat-uroki
   https://getdoday.ru/blog/razbor-vs-gdz
   https://getdoday.ru/blog/napominaniya-ob-uchebe-kotorye-rabotayut
   ```
10. Полезное там же, на будущее: **«Поисковые запросы»** (по каким словам находят),
    **«Диагностика»** (ошибки сайта).

## Шаг 2. Google Search Console

1. Открыть <https://search.google.com/search-console/welcome>
2. Выбрать правую карточку **«Ресурс с префиксом URL»** (не левую «Домен» — там нужен DNS)
3. Вписать `https://getdoday.ru` → **«Продолжить»**
4. В окне подтверждения раскрыть **«Тег HTML»** → скопировать код из `content="..."`
5. В `.env`:
   ```
   GOOGLE_SITE_VERIFICATION=<код>
   ```
6. Применить деплой-скриптом → в Search Console нажать **«Подтвердить»**
7. Слева **«Файлы Sitemap»** → в поле «Добавьте файл Sitemap» вставить и отправить:
   ```
   sitemap.xml
   blog/sitemap.xml
   qa/sitemap.xml
   pdd/sitemap.xml
   ```
   (здесь путь без домена — Google подставит его сам)
8. Сверху строка **«Проверка любого URL»** → вставить `https://getdoday.ru/blog`
   → после проверки кнопка **«Запросить индексирование»**. Повторить для 5–10 статей.

## Шаг 3. IndexNow — сказать поисковикам «придите сейчас»

Это push: вместо ожидания обхода мы сами отправляем список из 386 адресов
в Яндекс и Bing (Bing = ещё DuckDuckGo, Yahoo, Ecosia).

1. Сгенерировать ключ на сервере:
   ```bash
   openssl rand -hex 16
   ```
   Получится строка вида `3f2a91c8b47e0d65a1f8c3e920b74d1a`
2. В `.env`:
   ```
   INDEXNOW_KEY=3f2a91c8b47e0d65a1f8c3e920b74d1a
   ```
3. Применить деплой-скриптом
4. Проверить в браузере: `https://getdoday.ru/3f2a91c8b47e0d65a1f8c3e920b74d1a.txt`
   — должен открыться этот же ключ текстом. Отдельный файл создавать не нужно,
   сайт отдаёт его сам
5. Отправить все страницы:
   ```bash
   cd /var/www/getdoday/data/www/getdoday.ru/app
   uv run python scripts/indexnow_ping.py
   ```
   Ответы `200` или `202` = принято. Повторять после каждой большой публикации
   (`--only-blog` — только статьи, `--dry-run` — посмотреть список без отправки)

## Шаг 4. Метрика — смотреть, что происходит

Счётчик Яндекс.Метрики подключается переменной `YA_METRIKA_ID` в том же `.env`.
Если ещё не заведён: <https://metrika.yandex.ru/> → «Добавить счётчик» → домен
`getdoday.ru` → скопировать **номер счётчика** (только цифры) → `YA_METRIKA_ID=12345678`.

Смотреть потом: «Отчёты» → «Источники» → «Поисковые системы».
Внутренняя статистика посещений — на `https://getdoday.ru/app/root` (только для тебя).

## Что дальше, кроме техники

Индексация даёт попадание в базу поиска. Позиции растут от ссылок и поведения:

- **Анонсы.** Готовые тексты уже лежат в `docs/marketing/` — под vc.ru, Habr,
  Reddit, Show HN. Там же `HOW_TO_POST.md` с порядком публикации.
- **Площадки, где школьники и родители:** Telegram-каналы про учёбу и ЕГЭ,
  родительские сообщества ВК, «Мел», Пикабу, профильные подборки бесплатных сервисов.
- **Свой Telegram-канал** — анонсировать пачки статей, ссылка уже в футере сайта.
- **Соцсети в разметке.** Когда заведёшь аккаунты — добавить их в `sameAs` в
  JSON-LD Organization (`app/templates/landing.html`), это связывает бренд для поиска.

## Чего не делать

- Не покупать ссылки пачками и не размещаться в спам-каталогах — Яндекс за это
  накладывает фильтр, выбираться дольше, чем расти честно.
- Не рассылать сообщения в личку и школьные чаты без спроса — жалобы на спам
  бьют по репутации домена.
- Не копировать статьи на другие домены — дубли режут обе копии.
- Не менять URL уже проиндексированных статей; если очень надо — только через 301.

## Сроки, чтобы не разочароваться

| Когда | Что происходит |
|---|---|
| 1–3 дня | Яндекс и Google начинают обход, появляются первые страницы в индексе |
| 1–3 недели | Основная масса из 334 статей проиндексирована |
| 1–3 месяца | Трафик по низкочастотным запросам («как выучить стих за 20 минут») |
| 6–12 месяцев | Конкуренция по средним запросам («как быстро сделать домашнее задание») |

Проверять: Вебмастер → «Индексирование» → «Страницы в поиске» (должно расти к 300+).
