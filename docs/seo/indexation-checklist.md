# Индексация getdoday.ru: что нажать, по шагам

Инструкция под этот сервер. Всё, что можно было сделать кодом, уже сделано —
ниже только то, что требует твоих рук: подтвердить права в вебмастерах и
включить push-уведомления поисковикам.

Времени на всё: ~30 минут.

## Где на сервере лежит `.env`

```
/var/www/getdoday/data/www/getdoday.ru/app/.env
```

**Способ 1 — FastPanel (проще).** Открыть <http://192.168.33.3/> → «Файловый
менеджер» → пройти по пути выше → правый клик на `.env` → «Редактировать» →
дописать строку → «Сохранить».

**Способ 2 — SSH.**
```bash
nano /var/www/getdoday/data/www/getdoday.ru/app/.env
```

**Применить изменения `.env`** (после каждой правки):
```bash
bash /var/www/getdoday/data/www/getdoday.ru/app/scripts/deploy.sh
```
Скрипт перезапустит uvicorn и проверит, что сайт отвечает 200.

## Шаг 3. IndexNow — одна команда на сервере

Ключ на проде уже настроен (лежит в `.env` с прошлых времён), трогать его не надо.
Просто выполнить на сервере:

```bash
cd /var/www/getdoday/data/www/getdoday.ru/app
uv run python scripts/indexnow_ping.py
```

Скрипт сам проверит, что ключ отдаётся сайтом, и отправит 386 адресов в Яндекс
и Bing. Ответы `200`/`202` = принято. Если напишет, что ключ не подтверждён —
перезапусти сервис (`bash scripts/deploy.sh`) и повтори.

## Шаг 4. Метрика — смотреть, что происходит

Счётчик Яндекс.Метрики подключается переменной `YA_METRIKA_ID` в том же `.env`.
Если ещё не заведён: <https://metrika.yandex.ru/> → «Добавить счётчик» → домен
`getdoday.ru` → скопировать **номер счётчика** (только цифры) → `YA_METRIKA_ID=12345678`.

Смотреть потом: «Отчёты» → «Источники» → «Поисковые системы».
Внутренняя статистика посещений — на `https://getdoday.ru/app/root` (только для тебя).

## Что дальше, кроме техники

Индексация даёт попадание в базу поиска. Позиции растут от ссылок и поведения:

- **Анонсы.** Готовые тексты уже лежат в `docs/marketing/` — под vc.ru, Habr,
  Reddit, Show HN. Там же `HOW_TO_POST.md` с порядком публикации.
- **Площадки, где школьники и родители:** Telegram-каналы про учёбу и ЕГЭ,
  родительские сообщества ВК, «Мел», Пикабу, профильные подборки бесплатных сервисов.
- **Свой Telegram-канал** — анонсировать пачки статей, ссылка уже в футере сайта.
- **Соцсети в разметке.** Когда заведёшь аккаунты — добавить их в `sameAs` в
  JSON-LD Organization (`app/templates/landing.html`), это связывает бренд для поиска.

## Чего не делать

- Не покупать ссылки пачками и не размещаться в спам-каталогах — Яндекс за это
  накладывает фильтр, выбираться дольше, чем расти честно.
- Не рассылать сообщения в личку и школьные чаты без спроса — жалобы на спам
  бьют по репутации домена.
- Не копировать статьи на другие домены — дубли режут обе копии.
- Не менять URL уже проиндексированных статей; если очень надо — только через 301.

## Сроки, чтобы не разочароваться

| Когда | Что происходит |
|---|---|
| 1–3 дня | Яндекс и Google начинают обход, появляются первые страницы в индексе |
| 1–3 недели | Основная масса из 334 статей проиндексирована |
| 1–3 месяца | Трафик по низкочастотным запросам («как выучить стих за 20 минут») |
| 6–12 месяцев | Конкуренция по средним запросам («как быстро сделать домашнее задание») |

Проверять: Вебмастер → «Индексирование» → «Страницы в поиске» (должно расти к 300+).
