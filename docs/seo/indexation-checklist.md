# Как сделать так, чтобы сайт нашли: чек-лист индексации

Что уже сделано в коде и что нужно нажать руками. Порядок важен: сначала
подтверждение прав, потом sitemap, потом push-уведомления поисковикам.

## Уже работает (ничего делать не надо)

| Что | Где | Проверить |
|---|---|---|
| `robots.txt` со всеми sitemap | `app/main.py` | https://getdoday.ru/robots.txt |
| Карта блога (334 статьи + категории) | `app/blog/router.py` | https://getdoday.ru/blog/sitemap.xml |
| Общая карта сайта | `app/main.py` | https://getdoday.ru/sitemap.xml |
| Карты Razbery и ПДД | `app/qa/router.py`, `app/pdd/router.py` | `/qa/sitemap.xml`, `/pdd/sitemap.xml` |
| Atom-фид блога | `app/blog/router.py` | https://getdoday.ru/blog/feed.xml |
| Разметка BlogPosting, FAQPage, BreadcrumbList | шаблоны блога | [Проверка микроразметки Яндекса](https://webmaster.yandex.ru/tools/microtest/) |
| canonical, OG, Twitter-карточки | `app/templates/base.html` | посмотреть исходник любой страницы |

## Шаг 1. Яндекс.Вебмастер (главное для РФ)

1. Зайти на https://webmaster.yandex.ru → «Добавить сайт» → `getdoday.ru`.
2. Выбрать способ подтверждения **«Мета-тег»**. Яндекс покажет строку вида
   `<meta name="yandex-verification" content="a1b2c3d4e5f6" />`.
3. Скопировать **только код** (`a1b2c3d4e5f6`) и добавить на сервере в `.env`:
   ```
   YANDEX_VERIFICATION=a1b2c3d4e5f6
   ```
4. Перезапустить сервис (`systemctl restart doday`) и нажать «Проверить» в панели.
5. После подтверждения: «Индексирование» → «Файлы Sitemap» → добавить все четыре:
   ```
   https://getdoday.ru/sitemap.xml
   https://getdoday.ru/blog/sitemap.xml
   https://getdoday.ru/qa/sitemap.xml
   https://getdoday.ru/pdd/sitemap.xml
   ```
6. Там же: «Переобход страниц» — закинуть главную, `/blog` и десяток лучших статей.
   Лимит обычно 20–30 URL в сутки, остальное подхватится из sitemap.

## Шаг 2. Google Search Console

1. https://search.google.com/search-console → «Добавить ресурс» → «Ресурс с URL-префиксом»
   → `https://getdoday.ru`.
2. Способ подтверждения **«Тег HTML»** → скопировать код из `content="..."` и в `.env`:
   ```
   GOOGLE_SITE_VERIFICATION=<код>
   ```
3. Перезапустить сервис, нажать «Подтвердить».
4. «Файлы Sitemap» → добавить те же четыре адреса.
5. «Проверка URL» → вставить https://getdoday.ru/blog → «Запросить индексирование».

## Шаг 3. IndexNow — push вместо ожидания

IndexNow сообщает Яндексу и Bing о страницах сразу, не дожидаясь обхода.

1. Придумать ключ: случайная строка из латиницы и цифр, 8–128 символов
   (например `openssl rand -hex 16`).
2. В `.env` на сервере:
   ```
   INDEXNOW_KEY=<ключ>
   ```
3. Перезапустить сервис. Проверить, что https://getdoday.ru/<ключ>.txt отдаёт этот же ключ —
   эндпоинт уже есть в `app/main.py`, отдельный файл класть не нужно.
4. Отправить все 386 публичных URL:
   ```bash
   cd /path/to/project
   uv run python scripts/indexnow_ping.py            # всё
   uv run python scripts/indexnow_ping.py --only-blog # только блог
   uv run python scripts/indexnow_ping.py --dry-run   # посмотреть список
   ```
   Коды 200/202 = принято. Повторять после каждой большой публикации.

## Шаг 4. Что ускоряет попадание в топ, кроме техники

Индексация ≠ позиции. Дальше решают ссылки и поведение:

- **Ссылки на сайт.** Каталоги и площадки, где можно оставить нормальную ссылку:
  vc.ru, Habr, Пикабу, профильные Telegram-каналы про учёбу, родительские форумы,
  «Мел», ProductHunt (англ.), подборки бесплатных сервисов. Заготовки постов уже
  лежат в `docs/marketing/` — там есть тексты под vc.ru, Reddit, Show HN.
- **Telegram-канал проекта** — ссылка в футере, анонс каждой пачки статей.
- **Разметка организации** уже стоит; когда появятся соцсети, добавить их в `sameAs`
  (`app/templates/landing.html`, JSON-LD Organization) — это связывает бренд.
- **Скорость.** Блог кэшируется на диске, страницы отдаются быстро — это плюс к ранжированию.
- **Поведенческие.** Хорошая статья держит читателя: в блоге есть оглавление,
  прогресс чтения и перелинковка — это уже работает на глубину просмотра.

## Чего НЕ делать

- Не покупать ссылки пачками и не размещаться в спам-каталогах — Яндекс за это
  накладывает фильтр, выбираться из него дольше, чем расти честно.
- Не рассылать нежелательные сообщения в личные чаты и школьные группы — это
  портит репутацию бренда и попадает под спам-жалобы.
- Не дублировать статьи на других доменах — дубли режут обе копии.
- Не менять URL уже проиндексированных статей. Если очень надо — только с 301.

## Как понять, что работает

- Яндекс.Вебмастер → «Индексирование» → «Страницы в поиске»: должно расти к 300+.
- Search Console → «Покрытие»: сколько страниц проиндексировано.
- Яндекс.Метрика (счётчик уже подключён через `YA_METRIKA_ID`) → «Источники» →
  «Поисковые системы»: реальный трафик из поиска.
- Внутренняя аналитика: `/app/root` показывает топ страниц по посещениям.

Первые заходы из поиска обычно появляются через 1–3 недели, заметный трафик по
низкочастотным запросам («как выучить стих за 20 минут») — через 1–3 месяца.
