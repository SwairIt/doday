# Стайл-гайд статей блога Doday (`/blog`)

Обязателен для каждого, кто пишет статью в `app/blog/content/<категория>/<slug>.md`.

## Формат файла

```
---
title: Заголовок с ключевым запросом (до 70 символов, без точки в конце)
summary: 1–2 предложения, 120–200 символов. Попадает в карточку и meta description.
category: domashka          # slug из app/blog/categories.py
tags: дз, тайм-менеджмент   # 2–5 коротких тегов через запятую, нижний регистр
keywords: как быстро сделать домашнее задание, как делать уроки быстрее
published: 2026-08-25
emoji: ⚡                    # один эмодзи, по смыслу статьи
featured: true              # только для 6–8 лучших статей во всём блоге
---
Текст статьи в markdown.
```

Имя файла = slug: латиница, слова через дефис, транслитерация русского (`kak-bystro-sdelat-domashku.md`). Без дат, без стоп-слов вроде `i`, `v`, если можно обойтись.

## Структура текста

1. **Вступление (2–4 абзаца, без заголовка).** Сразу про боль читателя, конкретная ситуация («вечер вторника, три предмета, а ты открыл TikTok»). Не начинать с «В современном мире…», «Многие школьники…». Обещание: что будет в статье.
2. **`## Заголовки второго уровня`** — 5–12 штук, каждый под свой хвостовой запрос или вопрос. Внутри — `### подзаголовки`, где нужно. Оглавление строится по h2/h3, поэтому заголовки короткие и содержательные (до 60 символов).
3. Обязательные элементы (минимум 3 из списка в каждой статье): **таблица** (сравнение, план на неделю, чек-лист), **нумерованный список шагов**, **пример из жизни** (цитата/сценарий), **шаблон** (готовый план дня, текст сообщения учителю, скрипт разговора с родителями), **callout** через `> **Совет:** …` / `> **Ошибка:** …` / `> **Пример:** …`.
4. **`## Типичные ошибки`** — что делают все и почему не работает.
5. **`## Частые вопросы`** — 3–6 `### Вопрос?` с ответами в 2–5 предложений. Из этой секции автоматически собирается FAQPage для поисковиков — вопросы формулируй так, как их вводят в Яндекс.
6. **`## Что дальше`** — 3–5 ссылок на другие статьи блога (`/blog/<slug>`, только реально существующие slug из `docs/seo/content-map.csv`) + одна ссылка на продукт: Doday (`/auth/register`, `/for-students`) или Razbery (`/qa/`).

Объём — сколько нужно теме: от 1 200 до 4 000+ слов. Не растягивать и не резать ради «нормы». Вода и повторы запрещены: каждый абзац должен добавлять новый факт, шаг или пример.

## Тон

- На «ты». Дружелюбно, прямо, без сюсюканья и без назиданий. Как старший брат/сестра, который уже прошёл через это.
- Конкретика > общие слова. «Поставь таймер на 25 минут» вместо «правильно распределяй время».
- Юмор допустим, сарказм над читателем — нет.
- Нельзя: выдуманные исследования и проценты («по данным учёных, 87 %…»), выдуманные цитаты, ложные обещания. Если ссылаешься на факт — только общеизвестный или с реальной ссылкой (ФИПИ, Минпросвещения, Росстат, известные исследования: Эббингауз, Pomodoro Чирилло, spaced repetition Лейтнер, Deep Work Ньюпорта, Atomic Habits Клира).
- Внешние ссылки — 1–3 на статью, только на авторитетные ресурсы (fipi.ru, edu.gov.ru, gosuslugi.ru, mos.ru, официальные сайты сервисов).
- Никаких упоминаний нейросетей как автора. Не писать «как ИИ я…».

## Правда о продуктах (использовать только это)

### Doday Tasks — https://getdoday.ru
Бесплатный туду-лист и планировщик на русском. Работает в браузере (PWA — ставится на телефон как приложение) и как Telegram Mini App / бот **@DodayTaskBot**.
- Free-тариф бесплатно навсегда, без карты и без рекламы: 10 проектов, 500 активных задач, канбан, календарь, помодоро, статистика, лента активности, iCal-экспорт, корзина 14 дней, 3 кастомных фильтра.
- Pro — 199 ₽/мес, 1 990 ₽/год, 9 900 ₽ навсегда: безлимит проектов/задач/фильтров, премиум-темы, свои шаблоны проектов, корзина 30 дней, bulk-вставка 200 строк.
- Family — 299 ₽/мес, 2 990 ₽/год: Pro на 5 аккаунтов (для семьи с учениками).
- **Триала нет** — не писать «14 дней Pro». В бета-период все функции открыты бесплатно.
- Для учёбы: **расписание уроков** с предметами (у каждого предмета свой цвет и эмодзи — они заданы в сервисе, пользователь их не выбирает), **импорт домашних заданий из электронного дневника** — Школьный портал Московской области (authedu.mosreg.ru) и МЭШ (dnevnik.mos.ru): дз превращаются в задачи с датой сдачи; **напоминания** отдельно от дедлайна — приходят в Telegram-бот; **утренний email-дайджест** в 7:00 по Москве со списком на день (Telegram-бот и дайджест по тарифам относятся к Pro — в бета-период открыты всем бесплатно, так и пиши); **школьный стрик** и достижения (7, 30, 100 дней подряд); **экран «Сегодня»** с просроченным и дневной целью; **быстрый ввод** («физика §12 завтра !!!» → задача с датой и приоритетом); подзадачи любой глубины, лейблы, фильтры, помодоро на каждой задаче, привычки, трекер настроения, комментарии, совместные проекты (пригласить друга/родителя), тайм-трекинг, бэкап JSON/CSV/Markdown.
- Команды бота: `/add` (создать задачу), `/today` (задачи на сегодня), `/upcoming` (ближайшие), `/done` (показывает закрытое за сегодня — НЕ закрывает задачу), `/app` (открыть Mini App). Бот привязывается к уже созданному аккаунту, сам аккаунт не создаёт.
- Страницы: `/for-students`, `/for-teachers`, `/todoist-alternative`, `/pricing`, `/help`.

### Razbery — https://getdoday.ru/qa/
Школьное Q&A для 5–11 классов: задаёшь вопрос по предмету — получаешь **ответ с разбором** (объяснение логики обязательно), а не голое «ответ: 42». Слоган: «разбери, не спиши». Есть предметы и классы (`/qa/s/<предмет>/<класс>`), голосование за ответы, репутация, поиск, модерация, 1 500+ редакторских разборов. Бесплатно. Формулы (KaTeX). Не приписывать: нейросетевые ответы, платные тарифы, приложение в сторах, гарантии оценок.

### Другие продукты студии (можно упоминать вскользь)
Doday ПДД (`/pdd/`) — билеты ПДД с разбором; Lessio (`/lessio`) — кабинет записи для репетиторов.

## Конкуренты — как писать

Честно: признаём сильные стороны, называем реальные слабые (цена в валюте, нет русской локализации, нет расписания уроков, нет импорта дз, реклама, требуется карта). Не врать про их функции. Todoist, TickTick, ЛидерТаск, Notion, Google Tasks, Microsoft To Do, Any.do, Мяудза, Tweek, Strive; дневники — МЭШ, Дневник.ру, Школьный портал; для Razbery — Znanija.com (Brainly), Учи.ру, Skysmart, Foxford, ГДЗ-сайты (gdz.ru, euroki, resheba), ChatGPT/GigaChat/YandexGPT, Answers/Chegg.

## Markdown — что поддерживается

Заголовки `##`/`###`, абзацы, **жирный**, *курсив*, списки, нумерованные списки, таблицы (GFM), `code`, блоки кода, цитаты `>`, ссылки `[текст](url)`, `~~зачёркнуто~~`, `---` разделитель. Картинки не используем (нет хостинга) — заменяй таблицами, списками, эмодзи. HTML разрешён, но не нужен.
